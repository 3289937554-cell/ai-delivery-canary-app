# Variant B: Guided Execution

schema_version: product-design-variant/v1
issue_id: GH-3
variant_id: variant-b

Guided task-focused direction. This variant uses a release list and create form as the navigation rail, then gives the selected release a larger execution area with status, gate, risk, and audit sections in a predictable vertical rhythm. FLOW-001 remains fast because search and create are immediately available. FLOW-002 and FLOW-003 get stronger error recovery because release status, gates, and risks are grouped around the readiness decision. FLOW-004 remains readable because audit history has a full-width section after execution work.

This is the selected direction because it balances operational density with a clearer task sequence. It maps directly to the current application surface and preserves mobile order without creating a separate mobile product. Accessibility fit is strongest because labels, forms, allowed actions, flash feedback, and live announcements can follow one reading order.
